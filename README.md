#  Smart Inventory Management System

**Aptura Tech Solution — Batch 3 Internship | Week 3 | Task 1**

A practical object-oriented inventory management application built with
Python. The system demonstrates how classes, validation, persistence, and
reporting can work together to solve a real-world inventory problem.

---

##  Project Objective

The goal of this project is to build a maintainable inventory application
using Object-Oriented Programming principles.

The system allows users to manage products, organize them into categories,
track stock levels, search inventory, and generate summary reports.

---

##  Features

-  Add products
-  Update product information
-  Remove products
-  Search products
-  Product categories
-  Stock tracking
-  Low-stock detection
-  Inventory value calculation
-  Category-wise reporting
-  JSON-based persistence
-  Input validation
-  Error handling
